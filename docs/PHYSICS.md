# 科学模型与局限

## 参数与空间

采用 ¹⁷¹Yb 6s² ¹S₀ ↔ 6s6p ³P₀，两个态均为 F = ½、mF = +½。532 nm 光镊为理想线偏振标量模型。578 nm 驱动为 π 分量，Ω/2π 是独立输入。固定 25 个相同且独立的光镊，每个原子位于自身的光镊焦点。阵列 x–y 平面上的位点间距为演示设定的 6 µm，光镊沿 +z 传播。时钟光场示意沿 +x，模型使用跨阵列相同的方波驱动。

内部使用 SI。普通频率量 ν、Ω/2π、δ/2π 用 Hz，角频率 Ω、δ 用 rad/s，势能用 J。绘图标签用 µm、mW、kHz、MHz 和 µs。原子质量来自 NIST 同位素表，基本常数采用 CODATA 2022。

## 高斯光镊及 Stark shift

束腰 w₀ 为 1/e² 强度半径。计算使用 I₀ = 2P/(πw₀²)、zR = πw₀²/λ、w(z) = w₀√(1 + (z/zR)²) 和 I(ρ,z) = 2P exp(−2ρ²/w(z)²)/(πw(z)²)，其中 ρ = √(x²+y²)。P 为原子处功率。高斯束采用傍轴近似。束腰接近波长时，矢量聚焦效应可能需要额外建模。

计算 Uⱼ = −αⱼ I/(2ε₀c)，其中 α 用 SI。ΔU = Uₑ − Uᵍ，Δν = ΔU/h。模型 αₑ < αᵍ 且二者为正，因此两态皆束缚，³P₀ 较浅且钟跃迁蓝移。设 Dᵍ = −Uᵍ(0)/h，有 Δν(0)/Dᵍ = 1 − αₑ/αᵍ ≈ 0.61235。

3D 光束采用计算得到的 w(z)，透明度编码中心光强并压缩动态范围。势阱曲面是 z=0 的 U(x,y,0)/h，径向和轴向剖面通过同一空间势能函数计算。能量轴和空间轴用独立显示比例。钟跃迁图把自由原子的光学能隙压缩为示意高度，叠加同一比例的两态势能与激光偏置。

## 失谐、演化及 Bloch 球

局域共振为 ν₀ + Δν。以 νL − ν₀ 表示激光偏置，并用 δ = 2π[(νL − ν₀) − Δν] 直接计算。**自由原子共振** 取偏置 0。**手动频偏** 使用用户给定值。**已补偿** 连续跟踪所选位点的 Δν，包含大于手动探索上限的理论偏置。绝对光频是参考值加模型位移，用于溯源。动力学在偏置域计算，避免对两个浮点表示的绝对光频做差。

基底为 (|g⟩, |e⟩)，σz = diag(1, −1)。旋转波近似下，去除公共能量项，H/ħ = (Ωσx + δσz)/2。初态为 |g⟩。令 R = √(Ω² + δ²)、s = sin(Rt/2)/R，则 a = cos(Rt/2) − iδs，b = −iΩs。R = 0 时状态保持。Pₑ = |b|²，Pᵍ = 1 − Pₑ，Bloch 矢量为 (2 Re(a*b), 2 Im(a*b), |a|² − |b|²)，其中 a* 表示共轭。正 z 为基态。共振 π 时间为 π/Ω。光谱计算给定方波末端的 Pₑ，ν₀ 和 νlocal 标记各自的零失谐频率。某些脉冲面积下，零失谐位置可以是布居极小值。

演化限于脉冲内，画面在末端保留该时刻的状态。1× 将整段脉冲展开为约 4.8 s 的屏幕时间。快速失谐振荡在超过 100 周期时绘制布居上限／下限参考线，时间游标、布居读数、Bloch 矢量与导出仍用精确解析值。光束亮度和原子颜色是光场和理想布居的可视编码。

## 运动与适用范围

将高斯势在焦点展开到二阶。令 D = −U(0)，径向角频率 ωr = √(4D/m)/w₀，轴向 ωz = √(2D/m)/zR。界面给出两个态的径、轴阱频和最初三个径向谐振子能级的局域近似，能量估计高于逃逸阈值时隐藏对应能级。该近似要求波函数主要位于势阱的近谐区域。高能级或极浅势阱需用实际势能重新判断是否束缚。

当前模型忽略 Zeeman 位移、矢量光移、散射、加热、温度、运动耦合、光噪声、泄漏和检测误差。端点布居属于封闭两能级预测。模型以给定 532 nm α 输入为条件，完整的 ¹⁷¹Yb 标准不确定度仍待确定。网页的功率、束腰、Rabi 率与手动失谐范围用于软件探索。

## 一维运动研究

「一维量子化运动」使用两套不同曲率的谐振子波函数。径向 x 沿场景中的钟激光，取 kₓ = 2π/λ；轴向 z 垂直钟激光，取 k_z = 0。利用归一化 Hermite 函数的递推与复合 Simpson 积分，计算 Mₘₙ = ⟨e,m|exp(ikx)|g,n⟩。通过 iⁿ 重定相将偶、奇宇称的耦合统一为实矩阵。旋转系的 H/h 中，基态对角元为 nνᵍ，激发态对角元为 (m+½)νₑ − νᵍ/2 − δ/2π，耦合为 (Ω/2π)Mₘₙ/2。用实对称 Jacobi 对角化传播方波脉冲，并对截断归一后的初始 Boltzmann 布居作非相干平均。

表中的频偏以阱底共振为零点，等于 (m+½)νₑ − (n+½)νᵍ。红边带取 1→0，载波取 0→0，蓝边带取 0→1。阱底光移补偿后，0→0 仍有振动零点能差。轴向投影为零时，奇宇称边带耦合应消失。显示的 |M|² 是单条跃迁的耦合强度。热平均曲线同时传播基底内的各条耦合。

以 N 与 N+4 的曲线采样和脉冲末态作截断对照，并报告省略的热布居、地态反冲矩阵范数缺失及有限阱深的适用性提示。高温、浅阱或强反冲可能需要更大基底和实际势阱计算。初始温度是探索参数。理论背景见 [Blatt 等，光钟运动与拉比光谱](https://doi.org/10.1103/PhysRevA.80.052703)。

## 实验光移校准

在浏览器导入 CSV，记录文件名、数据来源和实验条件。拟合 Δν = b + a·P/w₀²，以光移的独立标准不确定度平方的倒数加权，同时报告斜率、截距、当前工作点的拟合均值与 1σ 不确定度、约化 χ² 和验证集误差。验证行只计算残差。功率与束腰按给定值处理，模型没有估计它们的测量误差或共同系统误差。超出拟合功率／束腰组合范围的结果标为外推。拟合结果在单独面板与条件模型比较。
