上述基准使用运行时两态 α 输入与 CODATA 2022。科学证据等级为条件理论及已测试的解析解。谐振子近似由解析曲率与有限差分交叉核对。Rabi 传播无积分步长，概率曲线只对解析解作图形采样。相邻光镊串扰、矢量聚焦、运动平均与实验校准未验证。

## 自动化测试

- `npm test`，24 项通过。覆盖原始物理基准、一维谐振子同阱与零反冲极限、解析反冲强度、基底截断对照、加权校准及输入校验。
- `npm run test:e2e`，5 个 Chromium 场景通过。覆盖 T17–T24、5 µs 深链接、一维运动轴切换、CSV 导入及留出验证。校准测试采用合成数据，检查方法和交互。
- `npm run build`，TypeScript 和 Vite 生产构建通过。Three.js 使主 JS chunk 触发 Vite 默认 500 kB 体积提示，gzip 约 225 kB。

浏览器调试初次遇到 Playwright 和系统缓存浏览器版本不匹配。安装匹配 Chromium 后定位到相机重置残留惯性及测试定位器的文本匹配范围，并在最终测试前修正。

## 渲染和性能

用 Chromium 检查桌面研究视图、三维势面、Bloch 球和 390 px 移动视口。Chrome 在 320、375、390、640、768、1024、1440 px 的布局检查中，页面无横向溢出且场景标签页完整显示。通过生产包冒烟验证：WebGL 正常，+471.2 kHz 蓝移、补偿零失谐及 5 µs 的 100% 理想激发均正确，浏览器未报告控制台错误或资源加载失败。硬件 Chrome 使用 Apple M2 的 ANGLE Metal 渲染器。1920 × 1080、DPR 1、Medium、默认阵列、补偿脉冲播放期间，105 个 requestAnimationFrame 间隔的中位数为 16.7 ms，P95 为 16.8 ms。该数据描述本机这一场景的浏览器帧节奏。其他设备、DPR 和满负荷操作下的帧率尚未覆盖。
