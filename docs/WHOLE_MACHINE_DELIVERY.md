# 中性原子量子计算机整机网站交付清单

访客可以从浏览器打开整机，选择电路和运行条件，沿同一条记录检查阵列、光路、门与读出，再按子系统找到相应的物理模型、数据来源和实测缺口。网页支持模拟、文献回放及本地文件导入。操控真实仪器需要另行确定装置、硬件接口、互锁与操作授权。

## 从工业孪生借鉴的两项设计

1. **风场按部件定义可解释的属性。** XMPro 将整台风机与转子分别建模。转子接口明确列出状态枚举，转速属性给出每秒转数的单位。用于本项目时，装载、阵列搬运、门控制和相机按子系统定位，每项观测旁标明装置和单位，让读者知道一次读数属于哪个部件、什么工况。核对的模型版本为 `3e4ef1a`。[XMPro 转子模型](https://github.com/XMPro/Wind-Power-Plant-Wind-Turbine-DTDL-Models/blob/3e4ef1ac080532b2f52d9640709a67e4f123d5d9/Wind%20Turbine/WROT.json) · [风机模型](https://github.com/XMPro/Wind-Power-Plant-Wind-Turbine-DTDL-Models/blob/3e4ef1ac080532b2f52d9640709a67e4f123d5d9/Wind%20Turbine/WTUR.json)
2. **工厂场景的显示取决于指定设备属性。** AWS CookieFactory 示例把设备组织为场景节点，用实体、组件和属性将搅拌机标签绑定到报警状态。这里对应的是用选定装置、轮号和回放时刻关联原子占位、驱动光路及已可用的读出。证据入口应能从组件定位到该过程，修正时间后各视图应共同更新。网站继续使用本地运行记录作为输入。核对的示例版本为 `f43414b`。[AWS 场景绑定源码](https://github.com/aws-samples/aws-iot-twinmaker-samples/blob/f43414b4dce7765e412b2e6c0e6738a5b93f3663/src/libs/scene_utils/samples/cookie_factory_sample/sample.ts)

## 正式定量验收仍需六项证据

同装置双曝光 CAL 继续收件。各项入件后按以下依赖执行，并将原件哈希、适用工况、分析版本、误差和筛选分母一并归档。公开网站的工程发布可先行完成。[正式验收顺序和收件索引](RELEASE_EXECUTION_CHECKLIST.md#正式科研验收顺序)

| 优先顺序与依赖 | 尚缺的数据 | 达标产物 |
| --- | --- | --- |
| 1. 双曝光 CAL 先导，随后全批 | 同装置已填写的工作簿和相机、控制日志，先导 m₁、m₀、空位各 100 轮。保留原始双帧、曝光时标、实际阈值和剔除原因。 | 对齐 300 个原轮号，报告异常与各组分母。先导通过后完成 CAL，归档冻结的阈值、比较符和筛选规则。[CAL 采集方案](SENOO_READOUT_ACQUISITION.md) |
| 2. 双曝光独立 VAL，等待 CAL 冻结 | 同装置另行采集的独立批次与原始帧，核对装置版本、工况、运行 ID。 | 用冻结规则计算错标、判丢失、歧义、各自分母及区间，保存可重算报告。[读出独立验证](SENOO_CALIBRATION.md) |
| 与 CAL 并行 · 装载与输运 | 同装置搬运前后占位帧、坐标标定、时钟、控制日志、存活结局及独立运行。 | 按轮还原路径，分别报告初装、目标装配、搬运存活及未知结局，核对两个独立运行。[输运收件](SENOO_TRANSPORT_ACQUISITION.md) |
| 与 CAL 并行 · 两原子 CZ | 同门版本的驱动、失谐、相位和相互作用标定，以及独立门响应、gRB 运行记录。 | 对冻结模型核对独立响应，再逐门深度查看三种筛选下的成功率、每门保真度及两种丢失，保留各自分母和误差。[CZ 数据交付](SENOO_CZ_ACQUISITION.md) |
| 与 CAL 并行 · 追溯扩展数据图 4f | 原拟合输入、实际时标、窗间采样或绘图拟合设置仍待公开。 | 追溯 2.4 µm 下四个时窗的选频依据。在获得原始记录前并列保留 4.24242 与 4.49 MHz。独立新扫描另作可分辨性检验。[原始记录需求](../references/knowledge/senoo-ed4f-author-data-intake.md) |
| 读出验证后 · 整机 Bell 独立批次 | 先冻结整机预测、容差和最低轮数，再收 ZZ、+π/4、−π/4 实际相位标定、双帧、筛选日志及经独立验证的读出版本。 | 逐组核对分母、布居、相干与目标态重叠及其联合区间，保留同装置组件版本和批次独立性。[Bell 采集方案](SENOO_BELL_ACQUISITION.md) |
