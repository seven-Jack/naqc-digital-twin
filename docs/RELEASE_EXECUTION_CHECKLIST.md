## Kim 公开双帧专题结项

2026-11-19 完成 Kim ⁸⁷Rb Exp34／Exp33 的跨装置对照归档。将 Exp34 的 X1／X2 中心和阈值原样用于 Exp33 时，8,810 / 1,115,928 个有序双帧位点对与作者归档有差异。改用 Exp33 分件中心后，ROI 留出帧仍有 2,817 / 1,673,892 个位点帧判决不同。固定计数、只切换为 Exp33 重算阈值，可逐个解释全部 2,817 个差异。按作者 70 箱规则重算的 198 个阈值全部落在归档值的 `1e-9 counts` 以内，5,636 轮的 1,115,928 个有序位点对全部匹配。该阈值使用了全部 Exp33 帧，零差异只用于同批复现。 [结项报告、分母和差异明细](../references/knowledge/kim-exp33-cross-batch.md)
