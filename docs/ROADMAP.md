# 扩展路线

1. **一维量子化运动。** 已实现不同曲率的谐振子基底、固定几何投影的反冲矩阵、载波和一阶边带、方波脉冲的热平均及基底截断对照。后续用实际有限势阱校核高温和浅阱区域，再加入多维运动和冷却方案比较。
2. **实验校准。** 已支持带来源的光移 CSV 加权拟合和留出验证。后续用同条件的 ¹⁷¹Yb 实测数据约束模型，引入功率、束腰及阱频的联合不确定度，扩展到 HDF5、Rabi 拟合及独立数据预测。
3. **驱动与计算扩展。** 基于受测的运动与失谐模型加入 Blackman、退相干和 Ramsey 序列。耗时扫描通过独立计算适配器扩展，保留浏览器解析基线。若未来获准接入 Taiyi，资源约束为 CPU ≤ 4、RAM ≤ 20 GiB，遵循共享服务器的实际调度要求。
