# 扩展路线

1. **一维量子化运动。** 实现两个不同曲率的束缚基底、固定几何下的投影波矢 k₅₇₈ 和 Mₘₙ = ⟨ψₑ,ₘ|exp(ikx)|ψᵍ,ₙ⟩，测试同阱极限、载波及红蓝边带、热平均和基底截断收敛。
2. **实验校准。** 引入带溯源的原子处功率／束腰／阱频测量和相同条件的 532 nm Stark 数据，约束 ¹⁷¹Yb 差分极化率及联合不确定度。支持本地 CSV/HDF5 导入、Rabi 和光移拟合及独立数据预测。
3. **驱动与计算扩展。** 基于受测的运动与失谐模型加入 Blackman、退相干和 Ramsey 序列。耗时扫描通过独立计算适配器扩展，保留浏览器解析基线。若未来获准接入 Taiyi，资源约束为 CPU ≤ 4、RAM ≤ 20 GiB，遵循共享服务器的实际调度要求。
