# ¹⁷¹Yb 中性原子量子计算机数字孪生架构方案

首版聚焦**整机流程和装置展示**。用户可以运行一段小规模线路，跟随同一个原子从装载、重排、门操作到成像，再从读出结果回溯到观测、判决规则和统计口径。整机采用配置驱动的事件回放，原子物理、装置参数、实验协议和运行记录分别版本化。先做通用框架，待装置确定后再补齐光路、坐标、编码与时序。

六行八列、九段流程、12 秒播放、理想 H/CZ 和合成读出作为迁移基线。483/460 nm 演示取材于 Muniz 门基准实验。首套具名文献装置采用 Senoo 767 nm 双曝光协议，使用单独配置及回放入口。 [整机演示](QUANTUM_COMPUTER.md) · [Senoo 装置](SENOO_APPARATUS.md) · [文献知识库](../references/knowledge/README.md)

  D["原子数据库和文献证据"] --> B["离线导入与版本锁定"]

| 层 | 职责 | 输出 |
| --- | --- | --- |
| 原子数据与证据 | 导入选定的版本，记录同位素、态、物理量、适用条件和出处 | 以 ID 引用的只读数据包 |
| 装置与校准 | 保存部件、功能区、坐标、通道、编码和操作能力。校准描述某装置在特定工作域内的有效参数 | DeviceProfile 与可选的 CalibrationSnapshot |
| 协议与编排 | 把门线路或实验步骤展开为带前置条件、资源和分支的操作计划 | ExecutionPlan 与诊断信息 |
| 执行与记录 | 执行理想线路、合成模拟或局部物理模型，或导入外部离线记录 | RunRecord，含状态变化、观测、判决与来源 |

**导入。** 选定本地快照，按量白名单生成可移植 JSON 和清单。清单包括文件 SHA-256、数据版本、源提交、原始记录 ID 和使用权限。每项输入保留原值、原单位、转换后的 SI 值及变换条件。原文档和实验原始文件在本地归档，运行包通过来源 ID、相对路径或内容哈希关联。

**求值。** 匹配同位素、态、波长用途、场、偏振、几何及装置后采用数据。Hz 与 rad/s、自然衰变率与线宽、1/e² 强度半径与直径、原子处偏振分量功率与入射总功率、J 与 F 约化矩阵元分别标注。未知参数保存为空并注明原因。缺少定量依赖时可播放注明依据的流程示意，有足够输入的组件仍可计算。

**参数绑定。** 以 578 nm 驱动为例，原子包提供跃迁和矩阵元约定，装置包提供通道与目标态，协议指定脉冲，校准包可提供适用条件下测得的 Ω/2π。若采用原子矩阵元计算耦合，模型另需明确的 F、mF、F′、mF′、偏振分量和相应原子处功率及束腰。每次运行记录实际采用的数值和方法，便于区分数据库推导、标定和手动演示输入。

## 3. 装置、坐标和协议

### 装置配置

- **空间。** 部件、功能区、位点、光阱和视场使用稳定 ID。三维机械示意、原子平面 SI 坐标和相机像素各有坐标系。有依据时附变换、原点、方向、比例和标定残差。只公开俯视图时，局部间距按来源绘制，腔体、镜架和光路长度按示意显示。
- **通道和能力。** 每束光记录 ID、波长、用途及目标，按证据补充原子处功率口径、束腰、偏振、传播方向和包络。装置声明固定阱、移动阱、共享 AOD、可用操作和相机曝光的约束。缺少依据的设备能力标为待定。
- **对象身份。** atomId 追踪粒子，siteId 标识位点，trapId 对应承载的阱。物理比特和逻辑比特通过运行内映射与原子关联。分别显示阵列容量、启用位点、占据数、求解的物理比特数和编码逻辑比特数。
- **编码和读出。** 配置给出逻辑 0/1 的态映射、量子化轴和读出协议。亮暗如何参与判决受前序制备、曝光、光泵和再泵影响。同名波长在不同配置中可以承担不同功能。 [编码及装置对照](../references/knowledge/apparatus-comparison.md)

### 操作计划

事件涵盖冷却、装载、重排、移动、同址换阱、制备、内部态转移、门驱动、曝光、判决和复位。每个事件记录 ID、目标、资源、依赖和可选的物理时长。搬运改变坐标，同址换阱改变阱归属，内部态转移改变状态或编码映射。门线路用 H、CZ 和测量基描述，具体配置提供可用的脉冲展开。连续哈密顿量实验可按专门协议加入幅度、失谐和相位波形及对应观测量。 [协议依据](../references/knowledge/model-requirements.md)

编排校验目标可达性、资源占用和分支依赖。同址两阱可按配置在交接期间重叠，共享 AOD 和相机按各自能力约束。依赖观测的操作在观测可用并完成判决后执行，每轮保留分支、重试、补位、跳过和超时。

~~~text
compile(protocol, profile, operationPolicies): ExecutionPlan
simulate(plan, parameterBindings, seed): RunRecord
importRun(file, provenance): RunRecord
projectFrame(run, playbackPosition, selectedAttemptId): PresentationFrame
summarize(run, selectionRule): Metrics
~~~

以上接口用于划分依赖。ExecutionPlan 保存计划时标和约束，RunRecord 保存执行过的事件、观测与判决。两者通过事件 ID 追查实际执行的偏差。图源只有聚合曲线或曝光计数时，可照实导入，相关逐轮时序保留为未知。

## 4. 运行、观测与回放

| 对象 | 最少内容 | 核心行为 |
| --- | --- | --- |
| 运行头 | 文件格式和模型版本、配置 ID 与版本、数据包与校准引用、参数摘要、来源、随机算法及种子 | 同版本和输入可复现合成运行。迁移时保留当前 JSON v2 导出入口 |
| 执行事件 | 计划 ID、尝试编号、事件类型、目标、资源、发生状态、时间与时钟来源 | 区分计划、执行、略过、失败和未知。多时钟有同步关系时保存转换和误差 |
| 观测与判决 | 曝光窗口、像素或计数引用、观测质量、算法版本、阈值及所依据的观测 ID | 亮、暗、歧义、缺测属于观测。原子存在性、计算态、泄漏、擦除分别记录来源及置信条件 |
| 指标 | 分子、分母、选择规则、样本量、误差、分析版本 | 分别展示全部尝试、成功装配、生存后选、有效读出和校正结果。GHZ 的 Z 基布居、X 基奇偶和相位扫描得到的相干量分别登记 |
| 播放快照 | 选定轮次和时刻、活跃事件、原子位置与状态、光路、可见观测和判决、累计统计及来源 | 时间轴、3D、2D、能级图和相机共用同一帧。播放、暂停、跳转只决定读取哪个快照 |

**时间。** 计划用秒或带单位的 tick，执行记录区分触发、曝光、数据到达与判决。播放器将相应区间映射到屏幕时间。物理持续时间未知时，保留顺序和动画时长。光束明暗的动画插值带示意标签，测得或计算的实际光强有独立读数。

**运行示例。** 首条交互演示用合成 Bell。先在阵列中识别两枚原子，重排到可操作的位置，播放 H、CZ 和指定测量基的读出。点击原子可同步追踪其身份、光路和所属阱；点击曝光可看到相机计数及判决依据；点击统计柱可追查尝试及分母。另提供装配不足、暗场歧义和条件补位的合成案例。WebGL 不可用时由同一快照生成二维阵列。

| 合成案例中的事件 | 写入运行记录 | 在画面上核对 |
| --- | --- | --- |
| 装载后搬运 | 初始占位、原子和阱 ID、起点、目标与轨迹 | 同一个 atomId 贯穿路径。初始占位与到达占位可对照 |
| 条件交接和门 | 同址旧阱→新阱、交接通过时安排逻辑门；失败时记入分支 | 交接前后坐标一致，允许两个通道同时亮。失败分支的门显示为略过 |
| 独立曝光与阈值 | 相机曝光、两帧计数、对应判决及其可用时刻 | 数据到达后可见观测，判决完成后显示分类 |
| 按判决补位 | 从观测引用回到补位触发。记录移入的原子及一次尝试结果 | 新补入的粒子有自己的身份，丢失前的原子记录仍可回查 |

首版导出单个版本化 JSON。若后来使用大量相机帧，可在本地数据包中把帧序列拆为带摘要的附件。导入先检查版本、单位和引用完整性，按实际来源识别逐轮记录与图源聚合数据；保持原事件次序及记录的实际分支。

**规模。** 大阵列的几何、占位和已记录轨迹可独立展示。小规模 Bell、GHZ 和叠加线路沿用现有求解。对于更多比特，按所用门集和观测量评估稳定子、局部模型或离线轨迹；完整态矢量的成本随比特数呈指数增长。先测加载、帧生成和拖动开销，再按瓶颈选 GPU 实例化、前缀计数、分块数据或 Worker。 [当前整机求解与播放](../src/physics/quantumComputer.ts)

## 5. 模型保真度与定量子系统

| 可交付层级 | 输出 | 所需证据 |
| --- | --- | --- |
| 流程演示 | 三维与二维流程，理想线路及合成装载、损失和读出 | 固定种子回归、不变量与视图同步 |
| 文献场景和离线回放 | 文献支持的布局、协议与图源；有时标的记录可逐轮重放 | 已核坐标与方法、图源和观测条件。逐轮回放另需事件与观测的关联 |
| 条件物理模型 | 在适用域内求光移、原子驱动、读出混淆或局部相互作用 | 匹配的能级和装置条件、明确近似及不确定度 |
| 同装置校准预测 | 在指定装置和工作域内预测可测的量 | 带条件的标定、独立留出、预定误差目标和不确定度覆盖 |

**成像与判决。** 优先用 Senoo 双曝光工作簿核对三组计数、态标签和坐标，共有未装原子、制备 m₀、制备 m₁ 各 255 对点。后续按选定装置的暗、亮与无原子对照组标定阈值、歧义区和误判，报告是否有生存后选。图源计数可以复核导入与图形，逐次全流程回放另需该装置的时序和观测。 [Senoo 源表](../references/knowledge/source-data.md)

**钟光移与驱动。** 复用当前 ModelSnapshot 的束腰、光强、势阱与两能级演化。同一参数快照供曲线、Bloch 球、运行记录及导出读取。失谐采用相对于裸线的激光频偏减差分光移，模型接口显式区分普通频率和角频率。现有 P/w₀² 加权拟合提供导入和留出方法，实测校准需纳入功率、束腰及其误差相关性。现有 R009 或 R016 保存结果供各自条件内的演示或敏感度参考；新装置的标定采用自身测量。 [钟物理与校准](PHYSICS.md) · [数据出处](REFERENCES.md)

**里德堡相互作用与门。** R017 目录支持有明确分支和偏振约定的零场耦合。两原子计算另需指定对态、间距、夹角、磁电场、能量参考与跟踪支系，区分相互作用能量、V/h 和 V/ħ。C₆/r⁶ 是特定支系和范围内的近似。接近 Förster 共振或有显著支系混合时，可在具备证据后接多通道模型或已计算的轨迹。预测门误差需要独立的驱动波形、态制备、运动、损失与读出约束。 [¹⁷¹Yb 光谱和门文献](../references/knowledge/ytterbium.md) · [相互作用图源](../references/knowledge/source-data.md)

| 3. 接入原子和观察数据 | 离线导入白名单原子快照与 Senoo 指定工作表。参数支持溯源和条件校验 | 哈希、行数、单位、误差条和带前导零的态标签与源一致。数据不确定度未知时可见其状态。本地包可独立运行 |
| 4. 建立首套具名装置 | 确定空间、光路、编码和协议后，完成一条可交付的整机展示路径 | 相关位点、光路、门和相机判决可回到源图及方法。未知尺寸有示意标识。具名配置通过共用回放接口 |
| 5. 标定并验证一个组件 | 选择一个装置、一类观测和适用域，获得配对的校准数据与留出批次 | 按日期、批次或工作点留出，报告拟合与预测残差、偏差、覆盖范围和区间。验收阈值按用途和测量噪声确定 |

每阶段运行 npm test、npm run test:e2e 和 npm run build。分别核对数据格式、条件、统计分母、量纲、概率归一、钟光移符号和可用基准。桌面、移动端与二维回退检查包含完整一轮、按事件暂停及跨视图一致性。科学预测使用独立实测验证。 [现有验收基线](VALIDATION.md)

首个实施切片抽取现有配置、统一光路投影并比对旧记录。固定 Z 基无噪声的理想 Bell 概率应为 00、11 各 1/2，有限轮次的合成计数与同种子的旧记录比较。再用合成分支检验失败、暗场和补位记录，随后引入文献装置和定量参数。

## 8. 校准所需数据

| 数据组 | 最少内容 | 支撑的能力 |
| --- | --- | --- |
| 装置与时序 | 装置版本、功能区、位点坐标、像素映射、通道、计划序列、触发与曝光时标、时钟同步 | 校准物理比例和实际时间，验证资源占用与反馈延迟 |
