## 标定、冻结和独立验证

1. **导入并核对来源。** 用本地 `#senoo` 的 **Senoo 实测工作簿**导入。按批次、尝试和位点对照原日志确认曝光配对与时序。检查纳入／筛除理由、缺帧及逐级分母，保留仪器原始计数和判决。正式流程接收已校验、声明为 `measured` 且具备必要条件和记录来源的批次。 [导入与回放](SENOO_APPARATUS.md#导入与校验)
2. **预定划分和验收口径。** 标定与验证使用不同采集运行，保留批次角色、划分时间和来源。先归档标定工作簿、留出批次身份和划分依据。留出工作簿可提前采集，冻结前保持封存。软件校验记录的身份和引用，划分时间及封存需要采集日志或实验记录佐证。
3. **只在标定批次评估候选并冻结规则。** 在 **双曝光正式标定与独立验证**选标定批次，填写两帧候选阈值及各自的 `≥` 或 `>` 比较方式，检查分组计数。勾选登记预设验收判据，填写下列参数，与阈值一起冻结。双亮保留为歧义，双暗在自旋组记作判丢失。冻结 JSON 保存规则版本、来源与输入哈希、适用工况、实际曝光与仪器阈值、筛选分母和逐位点判读，支持重算并对照仪器原判决。
4. **冻结后判读留出批次。** 导入留出批次 XLSX 并沿用当前冻结规则，或在新会话中导回保存的冻结 JSON。校验采集运行、原始帧引用和装置、协议、相机、ROI、计数处理及筛选口径。原始帧引用也检查筛除的已采曝光。同一份原图或计数日志的别名和内容需回查原件。工作点变化时作迁移检验。若验证后调整 ROI、阈值或筛选，更新规则版本并另外留出批次。

### 统计口径

各批次和制备组保存尝试轮次、尝试位点、制备通过、有效配对、原记录纳入、可判读及缺帧／跳过／无效帧分母或计数。原记录纳入与有效配对可重叠，按各自定义保留。用于判读的位点须在冻结的筛选口径内并具有两帧有效数值。

| 指标 | 分子和分母 |
| --- | --- |
| 自旋错标 | m₁ 误判 m₀ 或 m₀ 误判 m₁，除以相应自旋组的可判读配对数。 |
| 判丢失 | 自旋组双暗数除以该自旋组的可判读配对数。双暗由双帧判读给出，物理丢失的归因需占位或存活对照。 |
| 歧义 | 对应分组内的双亮数除以该组可判读配对数。汇总时明确采用的制备组。 |

附三类制备标签对四类判决的计数矩阵，分别报告全部尝试和条件样本的口径。误差区间记录置信水平、方法和统计单位。同一采集尝试复用相机曝光时，评估其对站点间误差相关性的影响。 [四种亮暗组合与论文对照](../references/knowledge/senoo-readout-calibration.md)

### 标定批次阈值扫描

在已校验的 `calibration` 实测声明批次中打开 **标定批次阈值扫描**。为两帧各填计数下界和上界，确定候选区内使用的每帧 `≥` 或 `>` 规则，再选排序目标。扫描和手动候选评估使用同一组已纳入且双帧计数有效的标定位点。留出批次的计数、标签与结果在此步骤保持封存。

扫描覆盖输入范围内所有互异的双帧判决区间。`≥` 用区间上端作代表，`>` 用下端，边界保留闭开关系和等号归属。按 **错误总数最少** 排序时，所有参加评估的位点等权，先比较错误总计。按 **最差制备组错误率最低** 排序时，先比较三组错误率的最大值。自旋组的错误总计包括错标、双暗判丢失及双亮歧义，空位组计单亮误报及双亮歧义。同分时依次比较另一统计量、第一帧和第二帧阈值。界面展示排名前 12 个候选。若范围内判决区间组合超过本地 100 万对的计算上限，可缩小计数范围后重跑。 [区间与排序实现](../src/physics/senooReadoutThresholdScan.ts)

**填入候选阈值** 将选定阈值填入现有候选表。点击 **评估候选阈值** 核对逐位点计数和分母，再冻结所选规则。切换到留出工作簿前可导出标定扫描 JSON，归档输入范围、等号规则、两轴判决区间、排序和选中候选，以及标定批号、运行和工作簿 SHA-256。排序依据为标定批次内的观测，实验判据仍由冻结规则在独立留出批次上核对。 [校准数据接入](../src/physics/senooMeasuredReadout.ts)

### 冻结验收判据与独立批次区间

冻结 JSON v2 保存总置信水平、尝试间独立性依据、三组各自适用的最低可评估尝试数和位点比例，以及八项条件错误率上限。m₁、m₀ 各报告错标、判丢失和歧义，空位组报告误报和歧义。计数和上限由各自的制备组解释。可评估位点比例以该组全部尝试位点为分母。旧版 v1 可导入并继续导出描述性判读。

区间按同一制备组内的采集尝试聚类。令第 $i$ 次可评估尝试包含 $n_i$ 个该组可评估位点，$N=\sum_i n_i$。同轮位点可相关。给定各轮纳入和位点数，采集尝试之间独立时，第 $i$ 次尝试对总错误率的贡献在 $[0,n_i/N]$ 内。联合置信水平为 $1-\alpha$ 时，各错误率使用的区间半宽为

$$
\sqrt{\frac{\sum_i n_i^2}{2N^2}\ln\!\left(\frac{16}{\alpha}\right)} .
$$

区间以观测率为中心，端点截在 $[0,1]$。Hoeffding 界允许同轮位点相关，Bonferroni 校正覆盖八项指标。区间针对筛选后、按位点数加权的期望率。采集顺序、原子复用或共用原始曝光若使尝试之间相关，须回查独立性依据。两批采集运行不同只证明批次身份分开。 [Hoeffding 不等式，定理 2](https://doi.org/10.1080/01621459.1963.10500830) · [NIST 同时区间说明](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)

同工况下，八项区间的上界都在预设限值内、各组最低样本条件均满足时，报告符合统计判据。任一下界超过限值时报告超出限值，其余未能判定的结果标为证据不足。校准与验证的率差按百分点报告。跨工况使用迁移标记。统计判据仍须和来源、封存记录及实验适用范围一并验收。 [独立批次计算](../src/physics/senooReadoutAcceptance.ts)

### 留出批次采集量估算

在查看留出数据前，从每项指标的预设上限减去标定批次或先导批次估计的预期率。每组用其中的最小差值作为区间半宽余量 $\delta$。若 $\delta\le0$，按当前预期率无法用扩大样本为该组取得正余量。

沿用上述区间时，定义有效尝试数 $n_{\rm eff}=(\sum_i n_i)^2/\sum_i n_i^2$。要求半宽不超过 $\delta$ 需要 $n_{\rm eff}\ge\ln(16/\alpha)/(2\delta^2)$。同组各轮可判读位点数相同时，有效尝试数等于可判读的独立尝试数。各轮位点数不均时，有效尝试数更少。采集预算应另外预留缺帧、制备失败和筛除，并同时核对最低可评估位点比例。

| 示例余量（百分点） | 95% 联合水平下每组所需有效尝试数（向上取整） |
| ---: | ---: |
| 5 | 1,154 |
| 2 | 7,211 |
| 1 | 28,842 |

示例仅用于估算当前区间方法所需的采集规模。实验的错误率上限、置信水平与可接受的证据范围按用途预定。即使达到计划尝试数，是否通过仍取决于留出批次实际判读结果和独立性证据。 [统计方法与实现](../src/physics/senooReadoutAcceptance.ts)

### 重算验证报告与关联整机

**导出独立验证 JSON** 生成 v3 报告，内含冻结档案、留出批次实际声明的工况、逐轮双帧、原阈值和来源，以及筛选、计数、区间和判据。v3 是验证报告版本，沿用已冻结规则本身的版本。重新打开页面可用 **导入独立验证报告 JSON** 重算计数、逐位点判决及通过／证据不足等结果。编辑后的摘要与重算不符时会提示冲突。此前的 v1／v2 验证导出仍可重算，实际留出工况以原工作簿核对。 [报告格式与重算](../src/physics/senooMeasuredReadout.ts)

另外导入原始验证 XLSX，可按字节 SHA-256 核对报告引用，并从工作簿再次重算。重命名的同一文件可匹配。报告重算核查文件内的记录与统计是否一致，原始 XLSX 校验确认软件处理的是同一个工作簿。实测声明、采集链和独立性仍要回查实验日志。

在 **整机电路独立批次**可导入验证报告并取用内嵌的冻结规则。若另外导入冻结规则，两份冻结档案须一致。整机采集运行及原始帧分别与读出标定和独立验证记录查重。同工况 v3 报告达到预设统计判据时可登记组件的统计证据。早期报告、跨工况或证据不足的结果可用于核对判读，整机报告记录其证据状态及来源。 [整机批次操作](QUANTUM_COMPUTER.md#senoo-独立电路批次)

### 两原子 CZ 的相干前向模型

计算基为 m₀、m₁。每个位点的 302 nm 驱动只耦合 m₁ 与 r₀，m₀ 为旁观态。两个位点各有一个三态空间，联合空间包含 9 个基态。写成角频率单位的哈密顿量为

$$
\frac{H(t)}{\hbar}
= \sum_{j=1}^{2}
\left[\frac{\Omega_j(t)e^{i\phi_j(t)}}{2}
  |r_0\rangle_j\langle m_1| + \mathrm{h.c.}
  - \Delta_j(t)|r_0\rangle_j\langle r_0|\right]
  + 2\pi V_{\mathrm{Hz}} |r_0r_0\rangle\langle r_0r_0| .
$$

每个位点的算符在另一位点作用为恒等。失谐零点、符号及相位参考沿用对应的标定记录。双激发态以该工况的单一有效频移描述，带符号的普通频率 $V_{\mathrm{Hz}}$ 乘以 $2\pi$ 后进入演化方程。

从 00、01、10、11 分别演化，报告计算基返回复振幅 $A_{xy}=\langle xy|U|xy\rangle$、返回概率 $|A_{xy}|^2$ 及门末计算基外的布居。这个模型中每种输入在计算基内可返回到自身，门末泄漏概率等于 $1-|A_{xy}|^2$。四个返回振幅的相位可辨时，条件相位取 $\arg(A_{11}A_{00}/(A_{10}A_{01}))$。理想 CZ 的条件相位为 $\pi$，比较完整计算基相位时还要核对局部 Z 补偿及其参考帧。

模型约定 Δ 为驱动角频率减去裸跃迁角频率，φ 与 Δ 在同一旋转框架下。相位调制由耦合项的 exp(iφ) 表示。归一化原始日志时，按这一框架填写 Δ，使同一调相效应只计一次，避免把它的时间导数再加到失谐。确认采用此约定后登记 `evolutionConvention`。

在 **两原子 CZ 波形输入** 的 **两原子 CZ 相干前向模型** 中，核对实测声明、时基和场参数。输入齐备后，在 **采样解释** 选 **左样点零阶保持**，填写 **粗步长上限 (ns)**，再点 **核对相干演化**。零阶保持沿用各区间左端样点的记录值，演化范围限于门窗内有覆盖的采样段。每个传播子步用位点独立驱动的解析传播，在其前后各施加半步双激发相互作用相位。

数值核对将每个粗传播步分成两个等长子步，重算同一波形并以细步结果展示返回、泄漏和条件相位。核对记录返回复振幅最大变化、门末泄漏概率最大变化以及折返到主值区间的条件相位差，作为传播离散化误差的诊断。任一返回振幅的模不超过 $10^{-12}$ 时，条件相位标为不可用。要核对零阶保持对原始驱动的逼近，还需实验的采样密度和时序依据。计算沿用录入相位参考，局部 Z 补偿值仍需配合原实验核对。**导出相干计算 JSON** 保存条件计算、传播选项、数值诊断及波形文件与原始记录的引用。 [传播与细化检查](../src/physics/senooCzDynamics.ts)

这些输出描述闭系统相干演化。实验门后丢失还受阱、擦除探测与电离影响，gRB 还依赖具体线路、筛选和读出。比较独立门响应前，需取得同工况的实际波形、阻塞频移、Z 补偿、读出标定、逐轮统计及相应不确定度。 [同装置实测证据](../references/knowledge/senoo-cz-reproduction.md#波形证据与仍缺的原始记录)

### 两原子 CZ 独立门响应

在 **两原子 CZ 独立门响应** 中点 **下载 CZ 门响应模板 JSON**。先归档待核对的实测波形、传播选项和预定的制备筛选与读出协议，再从独立采集的原始记录整理响应。响应针对同一台 ¹⁷¹Yb 装置、同一 302 nm 两原子 CZ 工况和门版本。导入波形并完成相干计算后，点 **导入 CZ 门响应 JSON**。对照核对 `waveformSha256` 与已导入波形文件的字节哈希、装置与门版本、工况和位点顺序，并检查响应和波形的采集运行 ID 不同。采集运行隔离及尝试间独立性需回查原始采集与划分记录。 [门响应导入](../src/physics/senooCzResponse.ts)

| 响应 JSON v1 字段 | 填写依据 |
| --- | --- |
| `kind`、`schemaVersion`、`sourceKind`、`sourceRef` | 类型填 `senoo-cz-response`、版本填 `1`。录入时声明实测 `measured` 或合成 `synthetic`，并引用原始响应记录。实测声明需核对原始数据。 |
| `waveformSha256`、`apparatusVersion`、`gateVersion`、`workingPoint`、`siteIds` | 登记实际导入的波形文件 SHA-256（64 个十六进制字符）与同工况身份。两个位点的顺序与波形 `first`、`second` 一致。输入标签的 0、1 对应 m₀、m₁，按该位点顺序组成 `00`、`01`、`10`、`11`。 |
| `acquisitionRunId`、`clockId`、`timeOriginRef` | 登记响应运行的身份与时基，保留可回溯的实验时标。若原始记录跨时钟，附对齐依据。 |

| `expectedAttempts`、`attempts` | 按原日志核对启动尝试总数。每条填唯一 `attemptId`、计划制备的 `input`、门前制备筛选 `prep`、`outcome` 和 `sourceRef`。门前筛除记作 `rejected`，结局字段填 `null`。纳入记作 `accepted`，并填写对应结局。 |
| `phase` | 可留 `null`。有独立条件相位估计时，填 `estimateRad`、`halfWidthRad`、`confidenceLevel`、`sourceRef` 和与待测波形约定一致的 `phaseReference`。半宽以 rad 表示，取值 0 至 π。来源引用保留实际相位分析数据及拟合方法。 |

所有门前纳入的尝试进入该输入组的分母。结局分为原态返回 `returned`、其他逻辑态 `other-logical`、已分辨的里德堡泄漏 `rydberg`、第一位点丢失 `first-site-loss`、第二位点丢失 `second-site-loss`、双位点丢失 `pair-loss`、歧义 `ambiguous` 和不可用 `unavailable`。每次尝试记一个结局。与当前闭系统模型对照时，`rydberg` 对应门末至少一个位点在 r₀，需要可分辨该布居的观测及独立转移或读出标定。物理丢失需有位点存活证据，双暗、缺帧和制备失败按各自证据归档。门前筛除仍保留在启动尝试总数中。

对每个输入组，令 $n$ 为门前纳入数，$x$ 为确认的原态返回数或里德堡泄漏数，$u$ 为各类物理丢失、歧义和不可用的合计。按现有判决，结局比例的下界和上界是 $x/n$ 与 $(x+u)/n$。给定门前筛选且尝试间独立时，以 $1-\alpha$ 跨四种输入同时报告原态返回和泄漏的概率区间。用 Hoeffding 半宽 $\sqrt{\ln(16/\alpha)/(2n)}$ 分别扩展已知结局比例的下界和上界，并把端点截在 $[0,1]$。$n=0$ 时保留分母并标记缺少该组证据。报告观测区间是低于、包含还是高于模型值，以及观测区间减模型值的残差范围。这些区间量化样本波动与未判明结局，对探测响应校准、模型误差及应用限值需另行核对。 [Hoeffding 不等式](https://doi.org/10.1080/01621459.1963.10500830) · [门响应对照](../src/physics/senooCzResponseComparison.ts)

导入的相位须对应 $\arg(A_{11}A_{00}/(A_{10}A_{01}))$ 的同一条件相位约定。相位参考一致且模型和实验均有值时，报告实验相位减模型相位的主值。区间跨越 ±π 时按圆周拆段显示。相位的置信水平沿用导入估计，与八项布居概率的同时区间分别报告。**导出 CZ 门响应核对 JSON** 保存对照及其来源。gRB 须另按线路深度、目标位串和筛选口径评估。单站点与相关丢失的实验验收也需要原始位点记录和适用的存活对照。 [图 3b–d 的分母与文献复现](../references/knowledge/senoo-cz-reproduction.md)

### 独立 gRB 与丢失批次

在 `#senoo` 的 **图 3b–d CZ 表征**下，打开 **两原子 CZ 波形输入**中的 **CZ gRB 与丢失独立批次**。下载 JSON v1 模板，保留查看留出数据前确定的线路协议、筛选口径、存活与读出标定、采集块划分依据及置信水平。`sourceKind` 填 `measured` 或 `synthetic`，实测声明需核对原日志。`waveformSha256` 使用所关联的实际波形文件字节哈希。导入后核查哈希、装置、门版本、工况及与波形不同的采集运行。结果报告位点顺序和波形一致的原子对数，其他原子对的工况适用性需核对实际逐对记录。 [批次模板与校验](../src/physics/senooCzBenchmark.ts)

| 记录 | 必填口径 |
| --- | --- |
| 批次 | `apparatusVersion`、`gateVersion`、`workingPoint`、`acquisitionRunId`、`sourceRef`、`protocolRef`、`maskRef`、`readoutCalibrationRef`、`survivalProtocolRef`、`independenceRef`、`confidenceLevel`。`mode` 填 `non-echo` 或 `echo`，`expectedAttempts` 是全部尝试中的原子对记录数。 |
| `sequences` | 每条线路的 `sequenceId`、`seed`、CZ 门数 `depth`、按位点排序的目标位串 `target` 和线路来源 `sourceRef`。保留已安排但欠采集的深度。 |
| `attempts` | 每条记录有物理采集轮次 `attemptId`、原子对 `pairId`、`blockId`、`sequenceId`、两个有序 `siteIds` 和原记录 `sourceRef`。同一物理轮次的多个原子对共用一个采集块。重复线路、共享曝光和跨轮漂移的依赖按采集设计归组。 |
| 筛选与结局 | `masks.prep`、`masks.decay`、`masks.loss` 保存三个真实纳入标志。`bitstring` 为可判定的观测位串或 `null`；`survival` 按位点填 `present`、`lost` 或 `unknown`。有已知存活状态时引用 `survivalRef`。 |

三种成功率各用其纳入原子对作为分母，观测位串与线路目标一致时计成功。确认有丢失或位串不同计失败。其余无位串结果保留为未判明。筛选交集从逐条掩码计数。单站点丢失按制备擦除组的两倍原子对数归一化，双位点丢失按原子对数归一化。双位点均证实丢失才计入分子，任何一位证实存活时可排除此事件。保留未知存活造成的计数范围及各自分母。 [图 3 聚合数据的口径](../references/knowledge/senoo-cz-reproduction.md#图-3b3c-的有效计数与分母)

设 $N$ 为对应分母、$x$ 为确认计数、$u$ 为未判明数，报告计数范围 $[x/N,(x+u)/N]$。若共预登记 $D$ 个门深度，给定筛选和各块大小，使用 $\sqrt{\tfrac{1}{2}\log(10D/\alpha)\sum_i n_i^2}/N$ 扩展区间两端，再截入 $[0,1]$。$n_i$ 是采集块 $i$ 在该指标的有效单位数，可以是原子对或站点。区间依赖各块之间独立，允许同块内相关，并覆盖五项指标的各个预登记深度。线路抽样泛化需另有采样设计及独立重复证据。 [统计计算](../src/physics/senooCzBenchmarkStatistics.ts)

非 echo 批次在结局完整、有效深度不少于三个时报告描述性拟合。gRB 使用图 3b 的固定渐近值 0、0、1/4，依次核对三条 $S(d)=a p^d+b$ 曲线与每 CZ 保真度 $1-(1-b)(1-p)$。两条丢失曲线允许自由截距。批次拟合按各深度的分母加权，报告残差和加权 RMS。无深度零时截距来自外推。拟合参数的置信区间需另按采集设计和独立重复估计。原始文献复现沿用作者图源的误差尺度。 [拟合实现](../src/physics/senooCzBenchmarkFit.ts) · [图 3b 源数据拟合](../references/knowledge/senoo-cz-reproduction.md#图-3b-的-grb-成功率和保真度)
