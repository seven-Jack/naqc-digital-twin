## 使用与补档

- 优先级 P1 对应第一版整机或需要首先理解的接口，P2 用于模块设计与后续扩展，P3 提供基础和路线背景。图节定位以所列刊版为准，预印本图号与分页可能不同。
- 论文题名与 DOI 指向正式出版记录。版本列描述本地保存的文本。一些论文与配套补充材料共用 DOI，按独立条目登记。预印本 DOI 以 `10.48550/arXiv.` 开头。
- 本地文件位于 `references/library/<主题>/`，按条目 ID 维护。保留作者稿时，正式刊版另存为 `<条目 ID>-publisher.pdf`。该目录被 Git 忽略。
- 本机 `/Users/seven/Desktop/paper` 补录材料已逐份核对。文献按 DOI、题名、版本及 SHA-256 去重，两个 XLS 与原索引的哈希和文件格式一致。
- 本轮以出版社、作者公开稿、机构库、官方手册为主要来源，按装置或可迁移的工程工作流选读。PDF 校验含文件格式、页数、题名匹配及代表性图页预览。
