# Knottnerus S23/P2 的冻结窗口留出对照

**同序列留出，⁸⁸Sr 跨装置对照。** 将 P1 的探测矩形、固定 3×3 像素和与候选判据 `sum > 6436 counts` 原样用于第二个参数点 P2。100 轮的 7,200 个位点帧中，有 **7,195 个判决与在线日志一致**。5 处差异均为日志判空、复算判占据。两种判决在末帧 1,600 个目标位上全部相符，首帧筛选却使入选轮数从 51 变为 53。 [全批摘要](data/knottnerus-s23-p2/results/summary.json) · [100 轮双帧、位串与名单](data/knottnerus-s23-p2/results/rounds.csv)

## P1 与 P2 的可比性

Knottnerus 等人使用 813 nm 光阱俘获 ⁸⁸Sr，在 689 nm 的 ¹S₀ ↔ ³P₁ 跃迁上采集荧光图。图 2 的几何是 6×6 初始阵列和内部 4×4 目标阵列，名义间距 6 µm。按作者笔记本 `AnalyzeFastSLMMovesPaper.ipynb` 的目标编号和首帧条件，在初态全部 36 个位点上数原子，以至少 16 个作为入选条件；再在末帧统计零基 ROI 7–10、13–16、19–22、25–28 的填充。P1 和 P2 是同一天、同一 S23 序列相邻的两个参数点，P2 没有用于挑选本次规则。 [论文图 2 与附录 A](https://pure.uva.nl/ws/files/312149130/SciPostPhys_19_4_118.pdf) · [作者数据包与分析笔记本](https://doi.org/10.21942/uva.28166483.v1)

| 核对项 | 公开记录 |
| --- | --- |
| 探测矩形 | `P1ROIs.dat` 与 `P2ROIs.dat` 逐字节相同，各 662 字节，SHA-256 均为 `518404c63edf75983eded294e786ace5f83f9fc74246598215730fe9439a047e`。36 个矩形的位置、尺寸和位点顺序全部一致。计算始终读取 P1 文件。 |
| 成像设置 | `P1.txt` 与 `P2.txt` 第 519–526、530 行记录相同的 SLM 成像参数与验证帧开关，包括 20 个周期、12% 占空比、200 ms 名义成像时长和启用验证图。两组的 `timinglist.dat`、`outputlist.dat` 也分别逐字节一致。这些文件记录程序设置，逐帧实际曝光与当时的在线 ROI 或阈值版本仍缺。 |
| 参数点区别 | `P1.txt` 与 `P2.txt` 第 4 行的控制字段 `DRbRepumpDPAOMB2Intensity1` 从 1.00000 变为 2.00000。其他文本差异为控制器结束时间和最近消息。这个字段不足以推断锶原子实际荧光亮度变化。 |

冻结规则取原图 `image[y0:y1, x0:x1]` 内的九个像素直接求和，不移动窗口、不扣背景，严格按 `sum > 6436` 判占据，等于阈值判空。6436 来自 S23 `params.dat`。P1 曾反推得到可匹配该批位串的整数阈值区间 6,480–6,550，本次未用这个区间选取 P2 的阈值。 [P1 冻结规则与判空追溯](knottnerus-p1-58-online-decision.md)

## 复算凭据与适用范围

随后固定本批的 ROI 与像素和，把 P1 区间内的 71 个整数阈值逐一用于 P2。P2_2 和 P2_16 分别从 6,482、6,499 counts 起退出首帧入选名单。 [逐阈值差异和分母](knottnerus-s23-p2-threshold-sweep.md)

Taiyi 于 2026-11-19 北京时间 17:22:09–17:22:10 完成作业。先核验公开数据 v1 的来源摘要、317 个工作包成员、P1/P2 设置及帧格式，再按冻结的 P1 矩形求和。主程序逐行读取原图的 3 个连续像素，独立程序用二维积分图计算同一矩形。两个程序按轮号、帧号、ROI 排序后得到相同的 7,200 个计数及双方判决，规范化全表的 SHA-256 为 `55f8dbecd05642c6b2b7919da29bb670e18554d3594531638fa01d7f91631d6a`。独立核对覆盖全部五条差异及九组筛选名单和分母。 [独立核验](data/knottnerus-s23-p2/results/independent.json) · [输入哈希](data/knottnerus-s23-p2/input-sha256.txt) · [输出哈希](data/knottnerus-s23-p2/result-sha256.txt) · [作业退出记录](data/knottnerus-s23-p2/compute-unit-final.log)
