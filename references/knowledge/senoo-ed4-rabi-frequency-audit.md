# Senoo 扩展数据图 4e、4f 的 Rabi 频率核对

图 4f 的 4.24242 MHz 和刊版 4.49 MHz 对应两组相邻拟合解。四个时窗中心相隔约 4 µs，两个解在相邻窗口之间约差一圈，所以在每窗中心几乎同相。在本次高斯包络模型中，允许每窗独立相位只消除了刊版频率额外加权残差的 **约 10%**。图 4e 也有约 0.25 MHz 的候选间隔，放开各窗相位后仍保留约 78% 的额外残差。公开材料足以核对采样造成的频率歧义。作者选择刊版频率的依据仍需原始时序和绘图拟合文件。 [Senoo 刊版](https://doi.org/10.1038/s41567-026-03258-8) · [逐窗数据](data/senoo-ed4-rabi-window-diagnostics.csv)

## 数据与比较方法

¹⁷¹Yb，767 nm 光镊与 302 nm 里德堡驱动。图 4e 的观测量为单原子 $P_{r_0}$，图 4f 为 2.4 µm 阻塞原子对的 $P_{r_0m_1}+P_{m_1r_0}$。两图均为丢失检测后的条件布居，每图 60 点、每窗 15 点。工作表 `ExtendedDataFig4e`、`ExtendedDataFig4f` 的 `B2:BI5` 保留原始 X、Y 及两侧误差。每点约 130 次有效测量，汇总九个原子或原子对。 [扩展数据图 4 原始 XLS](../library/171yb/yb-senoo-source-edfig4.xls) · [刊版 PDF 第 10、17 页](../library/171yb/yb-senoo-mapping-publisher.pdf)

沿用 [双原子复现的观测模型](senoo-pair-reproduction.md#扩展数据图-4f-的阻塞-rabi)，振荡中心取 0.5，包络为高斯，权重取 $1/s_i^2$，其中 $s_i$ 是该点上下误差大小的均值。每图比较两组频率。一组在宽频段内拟合（4e 为 2.5–3.75 MHz，4f 为 4–5 MHz），另一组固定为刊版频率。两组均以全图 60 点拟合各自的对比度、1/e 包络时间和共享相位。随后在每组内分别固定频率、对比度和包络时间，每窗只调整相位。

相位以每窗首尾时间的中点 $t_c$ 为参考，表中为 $2\pi f t_c+\phi$ 折回 $[-\pi,\pi]$ 的弧度值。它描述布居余弦在该时间的相位。RMSE 来自模型减观测的布居残差，以百分点表示。加权残差平方和为 $\sum_i[(P_{\mathrm{model},i}-P_{\mathrm{obs},i})/s_i]^2$。

| 图与频率 | 共享相位 RMSE（百分点） | 独立相位 RMSE（百分点） | 加权残差平方和，共享 → 独立 |
| --- | ---: | ---: | ---: |
| 4e 源表 2.99730 MHz | 4.53 | 4.10 | 102.32 → 85.95 |
| 4e 刊版 3.24 MHz | 11.53 | 10.07 | 611.28 → 483.11 |
| 4f 源表 4.24242 MHz | 5.89 | 5.63 | 127.43 → 119.60 |
| 4f 刊版 4.49 MHz | 8.27 | 7.89 | 268.39 → 246.54 |

4e 的四个窗口在独立相位下仍均支持较低频率，窗内 RMSE 分别为 3.23／11.70、3.50／9.99、3.86／9.72、5.45／8.60 个百分点（源表／刊版）。4e 刊版频率的额外加权残差平方和减少 21.96%。两图使用同一复现口径时，原子对与单原子的频率比为 1.41541，接近理想阻塞的 $\sqrt2$。两图刊版标注之比为 1.38580。

若时窗中心严格等距 $\Delta t$，相隔 $1/\Delta t$ 的两个频率在相邻窗中心恰好差一圈。下表按源表各窗首尾的中点计算，保留源表给出的时间间距。

| 图 | 实际频率差（MHz） | 平均中心间隔的倒数（MHz） | 相邻窗中心多计的周期数 | 单窗从头到尾积累的相位差（rad） |
| --- | ---: | ---: | --- | ---: |
| 4e | 0.24270 | 0.24962 | 0.975、0.971、0.971 | 1.00–1.05 |
| 4f | 0.24758 | 0.24976 | 0.993、0.990、0.990 | 0.73–0.76 |

跨窗间隔解释了候选解相距约 0.25 MHz 的尺度。每窗有有限长度，两组频率即使在中心同相，仍会在窗内逐渐错开。这与独立相位调整后仍留有较大残差差距相符。9.95%／21.96% 只量化独立相位所能削减的额外加权残差。采集时钟、物理驱动频率和作者选解原因需相应原始记录核实。

## 复现命令

图形坐标与随刊源表的比对使用 `xlrd` 2.x 和 `pdfplumber` 0.11.9。在项目根目录运行以下命令。共用图版可从上列任一官方源包提取，按归档路径保存。解析过程校验 XLS 和图版 SHA-256，输出两图各 60 点的图形差值。

```sh
python3 -B scripts/extract-senoo-pair-source.py |
  python3 -B scripts/compare-senoo-ed4-figure-source.py
```

在项目根目录使用现有 Node 依赖与 xlrd 2.x。命令校验源工作簿、写出 16 行逐窗 CSV，并在标准输出给出精确拟合参数、相位诊断及采样间隔。

```sh
bundle=$(mktemp -d /tmp/ybqc-ed4-windows.XXXXXX) &&
  python3 -B scripts/extract-senoo-pair-source.py > "$bundle/source.json" &&
  ./node_modules/.bin/esbuild scripts/diagnose-senoo-rabi-windows.ts --bundle --platform=node --format=esm --outfile="$bundle/fit.mjs" &&
  node "$bundle/fit.mjs" references/knowledge/data/senoo-ed4-rabi-window-diagnostics.csv < "$bundle/source.json"
```
