# 整机装置候选与比较条件

原 483/460 nm 展示基准采用 Muniz 的门实验，其公开资料覆盖交互行、两套共址光镊、门光路和读出序列。首套具名文献装置已选定 Senoo 767 nm 双曝光。下表保留选型时对目标场景与可用证据的比较。 [整机演示](../../docs/QUANTUM_COMPUTER.md) · [Senoo 装置](../../docs/SENOO_APPARATUS.md)

## 跨装置对照如何使用

- ⁸⁷Rb 分区处理器、¹³³Cs 逐址门和低温方案用于比较布局、资源约束、可并行门、连续装载及回放粒度。它们的数值按相应的阱、束路和观测条件入库。 [中性原子对照](neutral-atoms.md)
- 离子阱、超导、光量子和硅自旋最有价值的对照项是存储区和操作区占用、硬件时钟、控制和采集接口、判决与反馈延迟、校准版本。软件手册提供序列、资源和日志结构的参考。 [工程及跨平台对照](cross-platform.md)

## 选型讨论的输入

从上表挑出能覆盖首要用户任务的配置，对照以下问题。实测覆盖、调度兼容和展示成本各自记录。缺数据的单元注明需要哪种数据，公开图中的示意尺寸和有测量依据的尺寸各有字段。

| 比较维度 | 需要确认的证据 |
| --- | --- |
| 首次使用要看懂的过程 | 单次电路、真实分区反馈、原位隐藏、连续补给，或多能级观测，分别对应哪一条可复现的任务。 |
| 三维场景能复现的深度 | 位点与区几何、成像视角、已公开光路、动态路径、压力或室温／低温等边界条件，逐项注明示意或实验来源。 |
| 动力学能验证的深度 | 是否有同装置的束腰、原子处功率、阱频、态映射、脉冲和误差，是否有能留作独立验证的观测记录。 |
| 调度和观测可判别性 | 原子运输、阱间交接、内部态转移、驱动、成像和经典反馈是否能分开回放。 |
| 开发与扩展 | 对现有输入、固定种子、深链接和导出的迁移范围，是否能同时表达简单线路和分区循环。 |

选型前可以确定共用数据结构、证据格式和回放验收。具体波长、默认编码、位点坐标和误差参数在选定装置与条件后填写。 [模型构建约束](model-requirements.md)
