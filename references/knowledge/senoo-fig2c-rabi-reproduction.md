# Senoo 单原子 302 nm Rabi 文献复现

用 Senoo 等图 2c 右图的 80 个时间点复现 ¹⁷¹Yb 的 m₁↔r₀ 单原子条件布居。模型使用 767 nm 光镊装置的 302 nm 单光子驱动工况。逐点结果保留两态原始布居、非对称上下误差、预测及残差。 [论文图 2c](https://doi.org/10.1038/s41567-026-03258-8) · [80 个时点的逐点结果](data/senoo-fig2c-rabi.csv)

## 输入与筛选

- 刊版第 905 页图 2c 右图，源表 `Fig2c_right_blue`（m₁）和 `Fig2c_right_red`（r₀）的 `B2:CC5`。共同时间 0.01–1.00 µs。行 2、3 为时间和条件布居，行 4、5 为下、上误差的大小。刊版图 1 图注给出的布居误差一般约定为二项分布 68% 置信区间。
- 从 m₁ 出发驱动 r 比特。探测先施加 m 比特 π 脉冲，再施加 r 比特 π 脉冲，将两态映射到亚稳态流形后进行带丢失检测的自旋测量。布居按通过最终丢失检测的观测归一化。图 2c 源表未给出每时点原始尝试数、有效分母或丢失率。
- m₁ 与 r₀ 的观测布居之和在数值精度内为 1。拟合使用 r₀ 的 80 个观测，报告两态在同一时间轴的逐点预测。包括 `BO` 的边界数据（r₀=1、上误差=0），无删点。 [原始 XLS](../library/171yb/yb-senoo-source-fig2.xls) · [原始快照与校验和](../../src/data/senooPopulationSource.ts)

## 模型与拟合

以前向两能级共振响应为基线。驱动时间 $t$ 用 s，有效频率 $f$ 用 Hz，相位 $\phi$ 用 rad。共振模型取 $\Delta=0$ 和 $\Omega=2\pi f$。设 $L,H$ 是 r₀ 条件布居的低、高极值，则

$$
P_{r_0}(t\mid\mathrm{pass})=L+(H-L)\sin^2\!\left(\frac{2\pi f t+\phi}{2}\right),
\qquad P_{m_1}(t\mid\mathrm{pass})=1-P_{r_0}(t\mid\mathrm{pass}).
$$

在 $2.5\le f\le4.0$ MHz 内扫频及一个相位周期，逐级细化频率和相位网格。每个候选点在 $0\le L\le H\le1$ 内求解加权最小二乘。权重为 $1/s_i^2$，尺度 $s_i=(\mathrm{下误差}_i+\mathrm{上误差}_i)/2$。这一权重使用公开误差条的大小作近似。CSV 保留原始两侧误差，覆盖统计直接用原来的非对称区间。

| 量 | 拟合值或导出值 |
| --- | ---: |
| 有效振荡频率 $f$ | 3.02209 MHz |
| 相位 $\phi$ | −0.03701 rad |
| 条件布居下限 $L$ | 0.005293 |
| 条件布居上限 $H$ | 1.000000（达到约束上界） |
| 有效对比度 $H-L$ | 99.4707% |
| 共振模型 π 时间 $1/(2f)$ | 0.16545 µs |
| 含相位偏移的第一个峰位 | 0.16740 µs |

论文报告该图的对比度为 99.6(3)%。这里报告的是带物理边界的重拟合值。模型 π 时间由振荡周期导出。论文的约 0.15 µs 是探测映射步骤所报的 r 比特 π 脉冲时长。上限参数处于边界，缺少逐点有效计数和跨点相关性，拟合参数只报告点估计。 [论文正文及 Methods](../library/171yb/yb-senoo-mapping-publisher.pdf) · [前向模型](../../src/physics/senooRabi.ts)

## 逐点残差与验收

定义残差为预测减观测。平均带符号残差及 RMSE 以布居百分点报告。归一化残差是残差除以 $s_i$，用作诊断。

| 比较项 | r₀ | m₁ |
| --- | ---: | ---: |
| 核对点数 | 80 | 80 |
| 平均带符号残差 | −0.0367 个百分点 | +0.0367 个百分点 |
| RMSE | 2.1064 个百分点 | 2.1064 个百分点 |
| 归一化残差 RMS | 1.0994 | 1.0994 |
| 预测落在原始误差条内 | 47/80 | 47/80 |
| 最大绝对残差 | 5.1130 个百分点 | 5.1130 个百分点 |

最大绝对残差在 0.874684 µs（两表的 `BS` 列），r₀ 源值 0.77457、模型 0.82570。最大归一化残差幅度出现在 0.197975 µs（`Q` 列），r₀ 为 −2.227 个平均误差尺度。误差条之外的 33 个时点均保留在逐点记录中。 [80 个时点的逐点结果](data/senoo-fig2c-rabi.csv)

本切片的工程验收通过。80 对源点完整且逐点可定位，两态预测均在 [0,1] 内且互补。r₀ 的 RMSE 低于 3 个百分点，归一化残差 RMS 低于 2。两项阈值用于本切片的文献复现。误差条覆盖率作为额外诊断留档，以上数据与拟合使用同一条曲线。

## 适用范围

数值只用于图 2c 的 ¹⁷¹Yb m₁↔r₀、302 nm 驱动、0.01–1.00 µs 及其带丢失检测的观测条件。相位和布居上下限是有效观测参数，混合了可能的脉冲时间偏移、态制备、映射和读出效应。单条时间曲线缺少分别约束驱动强度、失谐、衰减、噪声与真实泄漏所需的观测。扩展数据图 4e–f 的驱动和阻塞曲线应按各自工况核对。读出正式标定依赖同装置逐轮实测及独立验证批次。 [双原子模型证据](senoo-gate-model-data.md#双原子能移和各向异性) · [读出实测缺项](senoo-readout-calibration.md#缺少的同装置实测数据)

## 复现命令

在项目根目录用现有 Node 依赖运行以下命令。程序打印来源、参数、诊断和验收结果，并保存逐点 CSV。安装 xlrd 2.x 的环境还可用 `python3 scripts/import-senoo-population.py --check` 对照原始 XLS。

```sh
bundle=$(mktemp -d /tmp/ybqc-fig2c.XXXXXX)
./node_modules/.bin/esbuild scripts/reproduce-senoo-rabi.ts --bundle --platform=node --format=esm --outfile="$bundle/fit.mjs" &&
  node "$bundle/fit.mjs" references/knowledge/data/senoo-fig2c-rabi.csv
```
