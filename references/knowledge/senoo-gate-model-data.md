# Senoo 单原子与两原子门的公开参数和验收数据

对象为 Senoo 等的 ¹⁷¹Yb 767 nm 光镊装置。核对刊版、原始 XLS 工作表及代表单元格。下文分别标记论文给出的典型条件、实验图源、报告的拟合结果和模拟结果。刊版位置按本地 PDF 从第 1 页起计。 [本地刊版](../library/171yb/yb-senoo-mapping-publisher.pdf) · [Nature Physics 论文](https://doi.org/10.1038/s41567-026-03258-8)

## 两原子 CZ 和后续观测

图 3 的 CZ 用 302 nm 光在 m 比特上实现，论文报告时间最优协议并对光学相位作正弦调制。每个 CZ 后施加电离脉冲，残余 r 布居计入可检测的丢失。369.5 nm、1 mW、40 µm 高斯束腰及约 0.03 µs 的电离时常数是该装置报告的探测参数。衰变擦除探测光在 CZ 期间关闭。非 echo 序列另有 Z 旋转补偿累积相位，优化指标为一个 20 CZ 序列实例的返回概率。门时长和实际相位调制参数仍待补。 [刊版第 4、10 页](../library/171yb/yb-senoo-mapping-publisher.pdf)
