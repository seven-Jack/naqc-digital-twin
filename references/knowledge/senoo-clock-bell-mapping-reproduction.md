# Senoo 图 1d 钟比特 Bell 映射文献复现

从图 1d 的 4 个布居和 60 个奇偶相位点复算，丢失检测后的钟比特 Bell 保真度为 **93.8541% ± 0.6142 个百分点**，与刊版 **93.8(6)%** 的中心相差 0.0541 个百分点。在图 1c、1d 都使用未做测量误差修正的同一复算口径时，保真度下降 4.6948 个百分点，其中 4.6508 个百分点来自测得的奇偶振幅下降。 [Senoo 刊版](https://doi.org/10.1038/s41567-026-03258-8) · [64 个源点及残差](data/senoo-fig1d-bell.csv) · [图 1c 复现](senoo-bell-reproduction.md)

## 映射序列和统计口径

Senoo 用 ¹⁷¹Yb、767 nm 光镊与 302 nm 里德堡驱动制备亚稳态 $m$ 比特 Bell 态。图 1d 把该态转到钟比特 $\{\lvert g_0\rangle,\lvert m_1\rangle\}$，纸面标签分别为 $g,m$。先施加 578 nm 钟比特 $\pi$ 脉冲，再施加亚稳态比特 $\pi$ 脉冲。按理想脉冲的基态交换，$\lvert m_1\rangle\mapsto\lvert g_0\rangle$、$\lvert m_0\rangle\mapsto\lvert m_1\rangle$。所以图 1c 的 00、11 对应图 1d 的 $mm,gg$，映射引入的相位另由脉冲参考决定。正文说明映射期间关闭光镊，以避免非魔术波长导致的差分光移。 [刊版 PDF 第 2–3 页，图 1b–d 及正文](../library/171yb/yb-senoo-mapping-publisher.pdf)

图 1c、1d 都汇总九对原子，并按丢失检测后保留的原子对统计。图 1d 的布居工作表 `Fig1d_left!B2:E5` 保留 $gg,gm,mg,mm$ 四态，并保留各态不对称误差。按 68% Clopper–Pearson 区间与比例反推下表的有效计数。 [图 1 源 XLS](../library/171yb/yb-senoo-source-fig1.xls) · [作者稿 v2，Error bars and fitting](https://arxiv.org/pdf/2506.13632v2)

## 奇偶振荡与刊版核对

沿用图 1c 的 $\Pi(x)=d+u\cos(2\pi x)+v\sin(2\pi x)$，以上下误差的均值计算权重 $1/s_i^2$。图 1d 拟合得 $d=0.03526422$、$u=0.89001910$、$v=0.03347232$，正弦相位偏移为 $+1.5332055$ rad。两图各自的拟合相位都跟随其分析脉冲参考。振幅 $A=\sqrt{u^2+v^2}$。以加权残差方差估计拟合协方差，再与聚合目标布居的二项标准误差按独立近似传播至 $F=(P_{\rm even}+A)/2$。表中复算不额外施加探测矩阵修正。

| 量 | 图 1d 复算 | 刊版 |
| --- | ---: | ---: |
| 目标布居 | 98.64330% ± 0.19449 个百分点 | 98.6(2)% |
| 奇偶振幅 | 89.06483% ± 1.21288 个百分点 | 89.1(1)% |
| Bell 保真度 | 93.85407% ± 0.61419 个百分点 | 93.8(6)% |

奇偶 RMSE 为 0.09134（奇偶单位），以点误差归一化的残差 RMS 为 1.43836。35/60 个拟合值落在原始非对称误差条内。最大绝对残差 0.23924，位于 `Fig1d_right!K2:K5` 的 $x=0.305556$。振幅中心值按一位小数舍入与刊版一致。本次得到的振幅标准误差约 1.21 个百分点，与刊版和作者稿 v2 的 89.1(1)% 按末位括号通常读法所得 0.1 个百分点有差异。保真度传播误差约 0.614 个百分点，与刊版 0.6 个百分点相当。作者对该振幅误差的定义与计算设置待核。 [刊版正文 PDF 第 3 页](../library/171yb/yb-senoo-mapping-publisher.pdf) · [作者稿 v2](https://arxiv.org/pdf/2506.13632v2)

## 对照图 1c 与可约束的映射损失

用相同加权模型与丢失检测口径对照两图，比较未修正结果。差值误差按图 1c、1d 的统计量独立近似合成。源表缺少跨图及跨位点的协方差。

| 指标 | 图 1c 亚稳态（%） | 图 1d 钟比特（%） | 1d − 1c（百分点） |
| --- | ---: | ---: | ---: |
| 目标偶数布居 | 98.73137 | 98.64330 | −0.08807 ± 0.27848 |
| 奇偶振幅 | 98.36639 | 89.06483 | −9.30155 ± 1.35050 |
| Bell 保真度 | 98.54888 | 93.85407 | −4.69481 ± 0.68946 |

按 $F$ 的公式，目标布居项贡献 −0.04403 个百分点，奇偶振幅项贡献 −4.65078 个百分点。对于有共同分析旋转的逻辑态，振幅与 $\lvert \rho_{gg,mm}\rvert$ 相关。以测得的两目标布居作为条件态对角项，由正性得到振幅上限 $2\sqrt{P_{gg}P_{mm}}$。图 1c 的对应上限为 98.72867%，图 1d 为 98.62112%。这两项的中央值差只有 0.10755 个百分点。实际振幅分别约为各自上限的 99.63%、90.31%，表明目标布居平衡之外的有效相干项下降。

| 公开数据可约束的量 | 仍需的证据 |
| --- | --- |
| 通过丢失检测的联合态布居，包括目标外 $gm,mg$ 观测 $48/3538$。 | 两个映射脉冲的分类转移率、钟比特探测错标矩阵及逐轮泄漏状态。 |
| 指定 Bell 线路、映射与钟比特分析链的条件奇偶对比度，以及随之改变的条件 Bell 保真度。 | 使用公共相位参考的输入与输出控制、分析脉冲校准、同批读出矩阵与逐相位四态计数，才能分摊映射脉冲、自由演化、分析与读出的影响。 |
| 筛选后每个统计点的有效计数。 | 筛选前总尝试数和按尝试／位点的存活、回俘、缺帧标记，用于绝对丢失率、每轮有效产率和按阶段归因。 |

出版方审稿附件第 3 页的作者回复把可能的机制定位在自由空间钟脉冲。按作者模拟，所估计的失谐量级对奇偶振幅影响很小，钟 $\pi$ 脉冲反冲引起的运动可使自由演化数 µs 内的波包重叠降低若干百分点。该解释来自作者模拟，映射损失各项贡献仍需回俘记录、自由演化时长、运动分布及同装置控制实验核对。 [出版方审稿附件，第 3 页，审稿人 2 问题 1](../library/171yb/yb-senoo-peer-review.pdf)

另外仍缺实际钟与亚稳态 $\pi$ 脉冲的幅度、失谐、相位和开关时标，图 1d 的拟合权重及误差定义。同装置**实际 CZ 门波形和正式读出标定继续等待实测**，读出验证使用独立批次。 [CZ 波形缺项](senoo-cz-reproduction.md#波形证据与仍缺的原始记录) · [读出实测缺项](senoo-readout-calibration.md#缺少的同装置实测数据)

## 复现命令

在项目根目录使用配置了 NumPy 和 xlrd 2.x 的 Python。脚本校验图 1 XLS 的 SHA-256，写出 64 行逐点 CSV，并用同一模型输出图 1c 对照差值。

```sh
python3 -B scripts/reproduce-senoo-bell.py --panel 1d references/knowledge/data/senoo-fig1d-bell.csv
```
