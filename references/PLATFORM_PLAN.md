# Muniz 483/460 nm 装置的候选展示草案

这份草案对应一个待比较的候选配置。新版的装置选型留待读完资料与比较之后讨论。如果采用这个配置，一条完整的两比特运行可以串起占位、AOD 搬运、原位换阱、门操作和荧光读出。用户从整机视图进入交互行，沿同一组原子观察各工序，并核对理想电路分布与模拟批次计数。 [知识库](knowledge/README.md) · [装置候选比较](knowledge/apparatus-comparison.md) · [Muniz 等，图 1、图 3、附录 A](https://doi.org/10.1103/PRXQuantum.6.020334)

## 本候选的装置和工序

| 工序 | 展示内容 | 证据与边界 |
|---|---|---|
| 装载与占位 | 在 483 nm 储备阱中显示随机占位，切换至俯视图看空阱和被分配的目标位点。 | Muniz 基准使用 12 行 × 7 列两套共址阵列。最外一行为交互区，含 7 个位点，行内间距 3 µm，距其余阵列 6 µm。演示占位由配置和种子生成。 |
| 重排与准备 | 高亮 AOD 送光与被搬运原子，显示位点坐标变化。到交互行后显示占位确认、冷却和 `0` 态准备。 | 483 nm 搬运光镊和交互行内准备来自附录 A。具体逐次路径由演示策略生成。 |
| 阱间交接 | 同一位点上，483 nm 储备阱逐渐减弱，460 nm 科学阱逐渐增强。侧边标出功率变化的方向。 | 论文给出 2 ms 线性斜坡。浏览器用单独的播放时长表现这一段。 |
| 门和测量基 | 优先用 Bell 电路串起局部拉曼与 CZ。选中 CZ 时按 578 nm 钟态转移、301.9 nm 里德堡耦合、578 nm 转回三步高亮，并标注虚拟 Z 校相。 | 光学步骤来自图 3。门结果仍由理想电路矩阵产生。X 基测量通过基变换再读出。 |
| 荧光与结果 | 回到共址储备阱，侧向 556 nm 探测与另一侧物镜收光分别高亮。相机视角显示亮暗示意和各位点判定，结果页给出有效尝试、装配失败和丢失。 | 论文典型曝光 5 ms。门表征的门前一帧、门后三帧可在说明中逐帧查看，显式标明合成图及其判定依据。 |

总览用于识别装置和光路，局部视图用于跟踪同一位点与同一原子。已知阵列尺寸标注在俯视图，光学台外形、机械件比例、完整实验循环时间使用示意表达。上游原子源可以标出功能位置，具体的 MOT 到科学腔输运方案可在采用具名实验配置时展开。 [Muniz 等，附录 A](https://harvest.aps.org/v2/journals/articles/10.1103/PRXQuantum.6.020334/fulltext) · [Norcia 等，装载与输运图 1](https://doi.org/10.1103/PRXQuantum.5.030316)

## 配置、运行和界面

1. **装置配置。** 记录配置版本、同位素与编码、坐标系、位点、功能区、光路和几何依据。用稳定的位点 ID 关联阵列、3D、相机示意和导出。参数与证据相连，能追溯到引用的图、节和适用条件。对文献未公开的坐标或机械尺寸，记录示意假设。
2. **运行序列。** 记录阶段、目标位点、操作类型和受影响光路。空间搬运改变位置，同址换阱改变原子的陷阱归属，门作用于量子寄存器，读出生成观测。文献给出的实验时长与浏览器播放时刻使用独立字段，单位在计算和展示边界做显式转换。
3. **结果与播放。** 延续 `createMachineRun → machineFrame` 的入口。运行生成批次和代表轮，播放帧从同一运行派生原子位置、正在工作的光路、当前门、读出和累计统计。场景、2D 降级画面、时间轴和面板使用这一帧。首轮图像与累计批次有各自的范围标识。
4. **版本与兼容。** 首个增量先用现有固定种子对照拆分前后的结果，再引入新的边缘阵列配置。48 位点合成模型和 84 位点文献配置的抽样空间不同，因此新增配置要随导出记录。旧 JSON 保持可识别，新增字段有明确兼容策略。保留整机、`#clock` 和补偿预设的深链接。532 nm 钟跃迁作为独立研究入口，链接处说明与 460 nm 科学阱的条件差异。

机器几何与运行指令的关系可参考 MQT NAViz。装置、校准与实验时序的边界可参考 LabOne Q 和 Pulser。分阶段存储原始观测、判决、经典分支和最终结果，可参考超导实时解码案例以及离子阱的中途测量。 [MQT NAViz](https://mqt.readthedocs.io/projects/naviz/en/stable/file_format.html) · [LabOne Q](https://docs.zhinst.com/labone_q_user_manual/getting_started/introduction.html) · [Pulser](https://docs.pasqal.com/pulser/sequence/) · [Google Quantum AI，图 4](https://doi.org/10.1038/s41586-024-08449-y) · [Pino 等，图 1](https://doi.org/10.1038/s41586-021-03318-4)

## 实施顺序与验收

| 增量 | 可验收结果 |
|---|---|
| **拆分现有整机流程** | 提取装置、序列、运行与播放帧的边界。相同现有配置和种子产生相同逐轮结果，Z/X 基的 Bell、GHZ 基准和导出回归通过。 |
| **完成论文配置的整机路径** | 真实浏览器可从整机总览进入边缘交互行。暂停或跳转任一工序，时间轴、说明、3D 和 2D 均指向同一阶段与位点。搬运有位置变化，2 ms 同址换阱只改变两阱贡献。 |
| **补齐相机与证据** | 相机示意与场景使用同一个代表轮和位点映射。空位、态判定与丢失可区分，测量尝试数等于有效、装配失败和丢失数之和。所有实验数字能回到文献图节，所有模拟输入能回到运行配置。 |
| **扩展到中途测量与补位** | 使用独立的五区配置展示测量、冷却、重置、占位反馈、条件搬运和补位。24 个逻辑比特、90 轮综合征等公开结果只在其实验条件下作为扩展证据。 |

每个增量运行 `npm test`、`npm run test:e2e`、`npm run build`，并在真实 Chromium 核对设施总览、交互行、换阱、门光路和相机视角。后续若拿到同装置实测，优先导入占位帧、搬运前后图像和曝光条件，分别核对装载、搬运存活、读出混淆与运行时序。门保真度使用独立基准和明确的后选口径。跨平台参数用于文献对照，具体仪器选型、反馈延迟预算和实验验收阈值留到目标装置与数据明确后确定。 [Muniz 等，图 4](https://doi.org/10.1103/PRXQuantum.6.020334) · [五区复用实验](https://doi.org/10.1103/v7ny-fg31) · [Reichardt 等](https://arxiv.org/abs/2411.11822v3) · [Toric-code 实验](https://arxiv.org/abs/2606.04079v1)

## 后续实验平台的接口与数据

| 子系统 | 首项需要拿到的实测记录 | 对应的数字孪生核对 |
|---|---|---|
| 冷原子源、加载与阵列 | 目标平面占位图、阱位坐标及其成像标定、重复装载记录 | 用占位图初始化运行，分别统计单位点装载率和整个寄存器填充率。 |
| 送光、搬运与双阱交接 | SLM/AOD 寻址映射、搬运前后同组原子的占位帧、双阱功率和时序记录 | 分别核对平面路线、阱间共址与原子存活。用实测时间校核关键事件顺序。 |
| 单比特与里德堡门 | 编码定义、光谱和驱动标定、线路及测量基、保真度与泄漏的统计口径 | 按装置和版本关联门模型。先对照已知工作点，再用独立测量核对预测。 |
| 相机、判决与经典反馈 | 曝光时标、位点级原始数据、阈值与状态标签、补位决策和执行记录 | 回放时依次显示观测、判决和条件动作，分别记采集时间、处理延迟和执行时间。 |
